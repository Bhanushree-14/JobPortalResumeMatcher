
# Job Portal and Resume Matcher

## About the Project

The Job Portal and Resume Matcher is a Java-based mini project that helps candidates find suitable job opportunities based on their skills.

Candidates can register by providing their name, email, and skills. They can view available job postings, select a job, and check how well their skills match the job requirements.

The system also displays matched skills, missing skills, matching percentage, and application status.

## Features

- Display available job postings.
- Candidate registration.
- Store candidate details and skills.
- Select jobs using job number or job name.
- Match candidate skills with job requirements.
- Calculate skill matching percentage.
- Display matched and missing skills.
- Track job application details.
- Validate user inputs and email addresses.

## How to Run the Project

1. Install Java JDK.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Compile the Java files:

   javac Job.java Candidate.java Application.java JobPortal.java

6. Run the project:

   java JobPortal
